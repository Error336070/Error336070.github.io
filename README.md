# atakemaltur.com

Source for [atakemaltur.com](https://atakemaltur.com), the site of Ata Kemal Tur (Error_33_6070): security advisories, research write-ups across security, quantitative finance and machine learning, and a contact for coordinated disclosure.

## Reporting a security issue or inquiry

Please don't open a GitHub issue for security reports. See the [contact page](https://atakemaltur.com/contact/) or [`security.txt`](https://atakemaltur.com/.well-known/security.txt). Encrypted email is preferred. If you don't use PGP, we can agree on another channel by email.

## Stack

- [Astro](https://astro.build) static site
- Content in Markdown (`src/content/advisories`, `src/content/research`)
- Self-hosted fonts (Geist and Geist Mono, SIL Open Font License), no third-party requests
- Deployed to GitHub Pages via GitHub Actions
